# THRDWRLD MEDIA

Built for the internet.

A world-class, production-ready website for a futuristic creative media house blending cinematic storytelling, modern SaaS UX, and premium agency aesthetics.

## Tech Stack
- Next.js (App Router)
- Tailwind CSS v4
- Framer Motion
- Lenis (Smooth Scroll)
- GSAP

## Getting Started

First, run the development server:

```bash
npm run dev
# or
yarn dev
# or
pnpm dev
# or
bun dev
```

Open [http://localhost:3000](http://localhost:3000) with your browser to see the result.
